# What if everyone became 10× stronger? (reel script, final)

Vertical 9:16, about 62 s, one narrator (ElevenLabs "Brian", eleven_v3), flat cartoon style.

## What changed from the draft, and why

| Change | Why |
| --- | --- |
| On-screen hook title **"WHAT IF YOU WOKE UP 10× STRONGER?"** from frame 1 | Most viewers decide in the first second, often with the sound off. The question is the hook. |
| Added **"Sounds awesome, right? Wrong. It's a complete disaster."** | The original opens with the premise and no conflict. This adds a reversal plus an open loop: *why* is a superpower a disaster? |
| Added a **2.5 s flash-forward montage** (smashed table, folded phone, snapped legs, pickle jar) | It shows the payoff before the story starts, so viewers stay to see how we get there. |
| "fold it in half **like a taco**" | A concrete, funny image beats "like paper". |
| "By **7:05** the **entire planet** is sold out" | A tighter timestamp makes the escalation feel faster and absurd. |
| Door / handshake / mom as **three one-line beats** with stamps (RRRIP!, BANNED, medical cross) | This is the fastest stretch of the reel; each beat is a pattern interrupt every 1.5–3 s. |
| **Record scratch + music stop** at "But here's the part nobody thinks about" | It resets attention right where reels usually lose people (about 30 s in). |
| "Your bones… *(beat)* didn't." as two separate takes | The pause is the joke, and the crack sound lands on "didn't". |
| "sprint **for the bus**" | It gives the sprint a reason and a visual (a bus pulling away). |
| End card: **"WHAT WOULD YOU BREAK FIRST? Tell me in the comments ↓"** | A comment prompt boosts engagement. The VO still ends on the punchline, so the loop back to the start is clean. |
