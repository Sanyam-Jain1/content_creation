# Page branding and setup

The page is a channel for **animated true stories: spies, cons, cover-ups**.
GARBO is the launch series (FILE 001). Future stories become FILE 002, 003…, so the
page never has to rebrand.

Visual board: `export/brand_board.png`. All assets: `export/`. Regenerate with
`node brand/export.js` (uses the same character rig as the videos).

---

## 1. Name

| Option | Handle idea | Why | Risk |
| --- | --- | --- | --- |
| **EYES ONLY** (recommended) | `@eyesonly.files` | A real classification marking ("for the eyes of the addressee only"). Promises secrets in two words. Works for any spy/con/cover-up story. The censor bar gives an instant visual identity. | Generic phrase: you can't own it; a small podcast used it (2020–22). |
| The Double Cross | `@thedoublecross.tv` | Nods to Garbo's real Double Cross System; strong for spies and betrayal. | Narrower (spies only); also a Ben Macintyre book title. |
| Paper Spies | `@paperspies` | Playful, matches the flat paper-cut animation style. | Sounds lighter than the dramatic tone of the videos. |

Check handle availability on Instagram, TikTok and YouTube yourself before deciding;
grab the same handle on all three. Fallbacks: `@eyesonly.stories`, `@eyesonlyfiles`,
`@eyes.only.tales`.

## 3. Bio

**Instagram** (≤150 characters):

```
🕵️ Real stories they never wanted you to see
Spies · cons · cover-ups, animated
📁 New file every week 👇
```

- Name field (searchable): `Eyes Only | True Spy Stories`. The name field is indexed by Instagram search; put the keyword there.
- Category: *Digital creator* or *Entertainment website*.
- Link: one link page (Linktree / Beacons) → YouTube, TikTok, "Sources for every file".

**TikTok** (≤80 characters): `Real spy stories they kept classified. Animated. New file weekly 📁`

**YouTube** channel description:
> True stories that were never meant for your eyes: double agents, impossible cons,
> wartime deceptions and cover-ups, told as fast animated files. Every story is real;
> dialogue is dramatised. Sources are in each video's description.
> New file every week.

## 4. Profile setup

- **Story highlights** (covers in `export/highlight_*.png`): `FILE 001` (Garbo parts + behind the scenes) · `SOURCES` (the fact sheet: real vs dramatised) · `NEXT` (polls on which story is next) · `ABOUT`.
- **Pinned posts** (pin 3): Part 1 (the hook), the best-performing part, and a 30 s "who was Garbo" trailer cut from Parts 1–4.
- **Grid**: every reel gets a custom cover (template: `export/cover_part1.png`). Rules: one face, a 2–3 word headline in Montserrat Black, a FILE label. Keep everything inside the central 3:4 area (1080×1440) so the grid crop never cuts it.
- **Series naming**: `FILE 001 · GARBO · Part 1/4`. Proposed change to the in-video badge: `GARBO · PART 1/4` → `EYES ONLY · FILE 001 · 1/4` once the name is final.

## 5. Captions, hashtags, posting

Caption template (first line is the hook, because only ~125 characters show before "more"):

```
He fooled Hitler with spies that didn't exist. 🕵️ (Part 1/4)

Juan Pujol was a chicken farmer Britain rejected three times…
so he became a "Nazi spy" and invented an entire army.

📁 FILE 001 · GARBO. Follow for Part 2.
Inspired by true events. Dialogue is dramatised. Sources: link in bio.

#history #ww2 #spy #truestory #dday #animation #historytok #espionage
```

- **Hashtags**: 5–8, mixing broad (`#history #ww2 #truestory`) with niche (`#espionage #dday #doubleagent #garbo`). Same set on TikTok; YouTube Shorts gets `#shorts` plus 2–3 topic tags in the title.
- **Cadence for the launch**: Part 1 → Part 2 two days later → Part 3 two days later → Part 4. Every post 18:00–21:00 in your main audience's time zone. Post the same file to Reels, TikTok and Shorts on the same day (export without platform watermarks).
- **Retention loop**: each part ends with "Follow for Part n"; pin a comment on each part: "Part 2 is up 👉 on the profile".
- **Engagement prompt** in pinned comment: "Would you have fallen for it? 🤔" or "Which spy story should be FILE 002?"

## 6. Compliance and rights

- Keep the `INSPIRED BY TRUE EVENTS` / "dialogue is dramatised" line in captions.
- Voices, sound effects and music are generated with ElevenLabs on a paid plan
  (commercial use included). Keep the account on a paid plan while you monetise.
- AI labels: the animation is clearly stylised; the voices are AI-generated. If a platform
  asks whether content is "altered or synthetic", answer according to its current policy
  (YouTube's disclosure covers realistic synthetic content; check the toggle at upload).
- Historical photos used for research are not in the videos; the characters are original drawings.
